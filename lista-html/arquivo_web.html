Linha do Tempo

Surgimento das redes de computadores - década de 1960

Começaram a surgir redes de computadores com o objetivo de permitir a comunicaçao e o compartilhamento de informações entre diferentes computadores.

ARPANET - 1969

A ARPANET foi criada nos Estados Unidos e conectou inicialmente universidades e instituições de pesquisa. Ela é considerada uma das principais percursoras da Internet.

Desenvolvimento do TCP/IP - 1970 a 1980

O TCP/IP foi desenvolvido durante a década de 1970 e passou a ser utilizado como padrão na ARPANET em 1983, permitindo a comunicação entre diferentes redes.

DNS - 1984

O DNS, Sistema de Nomes de Domínio, foi criado para facilitar o acesso aos computadores conectados à rede por meio de nomes, em vez de utilizar apenas endereços

World Wide Web - 1989

Tim Berners-Lee apresentou a proposta da World Wide Web enquanto trabalhava no CERN.

HTML e HTTP - 1990

Tim Berners-Lee desenvolveu teconologias fundamentais para a Web, incluindo o HTML e o HTTP, permitindo a criação e a comunicação entre páginas da Web.

Primeira página Web - 1991

A primeira página Web foi disponibilizada no CERN. A web começou então a ser utilizada e divulgada para outras pessoas.

Navegadores gráficos - 1993

Navegadores com interface gráfica ajudaram a tornar a Web mais acessível e contribuíram para sua popularização.

Web 1.0 - década de 1990

A Web era formada principalmente por páginas estáticas. Os usuários geralmente apenas acessavam e consumiam as informações.

Web moderna - anos 2000 até hoje

As aplicações Web passaram a ser mais interativas e dinâmicas, permitindo que os usuários criem conteúdos, enviem mensagens, façam compras, utilizem as redes sociais e realizem diversas tarefas diretamente pelo navegador.

Web 1.0

A Web 1.0, principalmente durante a década de 1990, era formada por páginas geralmnete estáticas. Os usuários tinham pouca possibilidade de interação e normalmente apenas acessavam e consumiam as informações disponível.

Aplicações Web modernas

As aplicações Web modernas são mais interativas e dinâmicas. Os usuários podem criar conteúdos, enviar mensagens, fazer compras, utilizar redes sociais, editar documentos e realizar diversas arefas diretamente pelo navegador.

Diferença entre Web 1.0 e Web moderna

Web 1.0: páginas principalmente estáticas, com pouca interação do usuário

Web moderna: páginas e aplicacções interativas, com conteúdos dinâmicos, participação dos usuários e comunicação entre usuários e sistemas.

Tim Berners-Lee e o CERN

Tim Berners-Lee foi o criador da World Wide Web. Ele trabalhava no CERN quando desenvolveu as principais teconologias que deram origem à Web.

Lista de definição

  • Internet: Rede mundial que conecta computadores e dispositivos, permitindo a comunicação e a troca de informações.
  • Web: Sistema de páginas e aplicações que podem ser acessadas através da Internet.
  • HTML: Linguagem de marcação utilizada para estruturar páginas da Web.
  • HTTP: Protoclo utilizado na comunicação entre navegadores e servidores web.
  • DNS: Sistema que relaciona nomes de domínio aos endereços IP.
  • Navegador: Programa utilizado para acessar páginas e aplicações da Web.
  • Servidor Web: Computador ou sistema responsável por armazenar e disponibilizar conteúdos para serem acessados pela Web.
