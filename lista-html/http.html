O que é HTTP?

O HTTP é um protocolo utilizado para permitir a comunicação entre navegadores e servidores na Web. Ele permite que o navegador solicite páginas, imagens e outros conteúdos, enquanto o servidor recebe as solicitações e envia as respostas.

Como funciona a comunicação HTTP

Quando uma pessoa acessa um site, o navegador envia uma requisição ao servidor onde o site está hospedado. O servidor processa essa requisição e retornar uma resposta, que pode conter uma página HTML, uma imagem ou outra informação.

Esse processo permite que os usuários acessem sites e utilizem aplicações Web.

Cliente e servidor

Cliente: é o programa que faz uma solicitação. Na Web, geralmente é o navegador, como Google Chrome ou Firefox.

Servidor: é o sistema que recebe as solicitações dos clientes e envia os conteúdos solicitados.

Requisição: é a mensagem enviada pelo cliente ao servidor, solicitando uma informação ou uma ação.

Resposta: é a mensagem enviada pelo servidor ao cliente, informando o resultado da requisição e podendo conter o conteúdo solicitado.

Métodos GET e POST

GET

O método GET é utilizado para solicitar informações ao servidor. Por exemplo, quando você acessa uma página para consultar um conteúdo, o navegador geralmente utiliza uma requisição GET.

POST

O método POST é utilizado para enviar dados ao servidor, como informações preenchidas em um formulário de cadastro ou contato.

Diferença entre GET e POST

A principal diferença é que o GET normalmente consulta informações, enquanto o POST costuma enviar dados para serem processados pelo servidor.

Exemplo de uma requisição HTTP

Uma requisição HTTP pode ser representada assim:


    GET /index.html HTTP1.1
    Host: www.exemplo.com

Nesse exemplo:

  • GET é o método utilizado para solicitar um recurso.
  • /index.html é o caminho do arquivo solicitado.
  • HTTP/1.1 indica a versão do protocolo.
  • Host informa o endereço do servidor.

Exemplo de uma resposta HTTP

O servidor pode responder assim:


        HTTP/1.1 200 OK
        Content-Type: text/html

        <html>
        <body>
        <h1>Bem-vindo ao site!</h1>
        </body>
        </html>

Nesse exemplo, o código 200 OK indica que a requisição foi atendida com sucesso. O cabeçalho Content-Type informa que o conteúdo enviado é HTML, e depois, aparece o conteúdo da página.

Códigos de status HTTP

Os códigos de status indicam o resultado de uma requisição feita ao servidor.

200 - OK

Significa que a requisição foi realizada com sucesso e o servidor retornou o resultado esperado.

301 - Moved Permanently

Indica que o recurso foi motivo permanentemente para outro endereço. O servidor informa o novo endereço para que o cliente possa acessá-lo.

400 - Bad Request

Significa que o servidor não conseguiu entender a requisição porque ela apresenta algum problema, como informações em formato inválido.

403 - Forbidden

Indica que o servidor entendeu a requisição, mas não permite o acesso ao recurso solicitado.

404 - Not Found

Significa que o recurso solicitado não foi encontrado no servidor. Isso pode acontecer quando uma página não existe ou o endereço foi digitado incorretamente.

500 - Internal Server Error

Indica que ocorreu um erro interno no servidor, impedindo que a requisição fosse concluída corretamente.
