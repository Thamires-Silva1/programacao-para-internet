Perguntas e Respostas

✅ Atividade 1 – O que é uma regra CSS?

Resposta: Uma regra CSS é um conjunto de instruções usado para definir a aparência dos elementos de uma página HTML, como cores, tamanhos, fontes e espaçamentos.

Uma regra CSS é formada por um seletor, uma propriedade e um valor.


        p {
            color: blue;
        }

✅ Atividade 3 – Como podemos incluir CSS em documentos HTML?

Resposta: Podemos incluir CSS em documentos HTML de três formas diferentes:

  • CSS Inline: é aplicado diretamente em um elemento HTML, utilizando o atributo style
  • CSS Interno: é escrito dentro da tag style, localizada no head do documento HTML.
  • CSS Externo: é criado em um arquivo separado, com a extensão .css, e conectado ao HTML pela tag link.
